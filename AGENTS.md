# Regras do portfólio

Estas regras se aplicam a todo o projeto.

- A cópia local é a fonte de trabalho. Nunca substituí-la pelo GitHub desatualizado.
- Não usar challenge-one-portfolio.vercel.app como referência ou destino: exibe outra pessoa.
- Não executar git add, commit, push, merge ou deploy sem autorização explícita.
- Antes de publicar, identificar e corrigir a divergência local/GitHub/Vercel com o usuário.
- Não alterar credenciais nem configurações de produção.
- Trabalhar em marcos pequenos: explicar escopo, implementar, validar e listar arquivos alterados.
- Explicar qualquer nova dependência antes de adicioná-la. Preferir HTML/CSS/JS nativos.
- Manter navegação direta para Projetos, Sobre, Formação e Contato. O modo game é opcional.
- Manter a paleta azul original nos temas claro/escuro; não trocar a identidade de cores sem pedido.

- Nunca bloquear conteúdo por progresso, pontuação ou animação.

- Não inventar formação, certificados, selos, conquistas, métricas ou decisões técnicas.
- Preservar evidências e links de origem; sinalizar informações que aguardam confirmação.
- Projetos dinâmicos devem manter conteúdo local útil sem JavaScript, API ou rede.
- Não expor tokens. Tratar respostas remotas como dados, sem injetar HTML não confiável.
